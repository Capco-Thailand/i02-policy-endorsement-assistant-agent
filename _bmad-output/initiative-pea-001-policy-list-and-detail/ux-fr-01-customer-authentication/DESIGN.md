# FR-01 visual design

## Brand & Style
A calm policy-service screen. It identifies the synthetic demo context before credentials are entered.

## Colors
Warm paper surfaces and dark ink carry policy content. The rust accent marks the primary action; red marks errors.

## Typography
Serif headings establish hierarchy; controls and body copy use a readable system sans-serif.

## Layout & Spacing
Use one narrow form column with generous whitespace. Keep the account context and sign-in action visible without scrolling on desktop.

## Shapes
Controls have modest corners and clear borders.

## Components
The sign-in form has explicit labels, an inline error region, and a single primary action. A plain text note marks the prototype as synthetic.

## Do's and Don'ts
Use direct policy-service language. Avoid gradients, glass, decorative illustrations, and claims that approval binds coverage.
